# 银斑潮盗蛛

**Hygropoda argentata**

## 形态描述

雌性：8～10 mm。体黑色，被黄褐色鳞毛，下表面灰色毛，上表面灰色或浅黄色毛。上颚扁，4齿，顶齿及第2齿间具沟，齿长达上颚基部；唇基及额唇基中央具光滑的纵纹；颊为复眼宽的1／2；中胸及小盾片刻点较唇基者小而密。唇基两侧及颜面密被白毛；胸侧、并胸腹节及腹部第1节背板密被白色长毛；腹部1～5节背板端缘具白毛带；第6节背板具2个圆白毛斑；腹毛刷白色；足被短的白毛；距浅黄色；后基跗节内表面黄褐色。

雄性：9～10 mm。颜面密被浅黄色长毛；触角第2鞭节短于第3节；前足基节具短的尖突；前足腿节宽，端部黄褐色，扁平，内表面凹，端部褐色；前足胫节基半部内表面凹，黄褐色；第3～4腹板密被红黄色绒毛；第6节背板被白绒毛，端缘扁平，两侧缘具不规则的小齿。

## 大小

雌性：8～10 mm。雄性：9～10 mm。

## 生物学

采访植物：苜蓿等豆科植物。

## 生境信息

采访植物：苜蓿等豆科植物。
