# 南昌后螯蜂

**R.C.L.Perkins nanchangensis**

## 形态描述

“雌：未知。雄：体长3．7 mm；长翅。体色：体黑色；触角褐色；上颚褐黄色；足褐黄色，仅后足基节基部黑色。头：有光泽，光滑，有小刻点；触角线状，被灰色短毛，毛长短于触角宽；触角末端不膨大，各节长度比例12．0：7．0：14．0：15．0：15．0：13．0：13．0：13．0：12．0：15．0；额线缺；POL=6．0；OL=4．0；OOL=9．0；OPL=8．0；TL=8．0；后头脊完整。

胸：中胸盾片、小盾片和后胸背板有光泽，较光滑，有小刻点；盾纵沟伸达中胸盾片长度的0．50；并胸腹节无光泽，背表面有网皱；背表面与后表面间有1条横脊；后表面有2条纵脊；中区和侧区有网皱。翅：前翅透明五色，无色斑；径脉端段与基段等长；翅痣的长约为宽的4倍(28．0：7．0)；径室开放。足：胫节距式1，1，2。腹：外生殖器的阳基侧铗有1个内突。
