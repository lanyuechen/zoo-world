# 沃氏后螯蜂

**R.C.L.Perkins whartoni**

## 形态描述

雌：未知。雄：体长2．3～2．4 mm；长翅。体色：头黑色；触角第1节褐黄色，第2～10节褐色；上颚褐黄色；胸部包括并胸腹节黑色；足褐黄色，仅后足基节基部褐色；腹部褐色。头：有光泽，光滑，有小刻点；触角线状，被灰色短毛，毛长等于触角宽；触角末端不膨大，各节长度比例6．0：3．5：5．0：5．0：5．0：5．0：4．5：4．5：4．0：7．0；额线很短，仅在前单眼前可见；POL=3．0；OL=2．0；OOL=4．0；OPL=2．0；TL=2．0；后头脊完整。

胸：中胸盾片、小盾片和后胸背板有光泽，光滑，有小刻点；盾纵沟伸达中胸盾片长度的0．80；并胸腹节无光泽，背表面有网皱；背表面与后表面间有1条强的横脊；后表面有2条纵脊；中区光滑；侧区有网皱。翅：前翅透明无色，无色斑；径脉端段明显比基段短(5．5：13．0)；径室开放。足：胫节距式1，1，2。腹：外生殖器的阳基侧铗有1个内突。

## 国内分布

台湾(南投)
