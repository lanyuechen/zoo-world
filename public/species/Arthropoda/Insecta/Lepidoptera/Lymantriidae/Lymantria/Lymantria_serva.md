# 虹毒蛾

**Lymantria serva**

## 形态描述

翅展  雄33～39mm，雌54～66 mm。形态    雌蛾触角干暗棕色，栉齿黑色；下唇须暗棕色，外侧黑色；头部和胸部暗棕色，两眼间颜色较浅；颈板红色；腹部红色，每节具黑色环带，腹部末端暗棕色；胸部下面暗棕色，腹部下面黑色；足暗棕色，具黑色斑，转节和腿节基部红色。前翅暗棕色，具灰白色斑纹，其上散布棕色鳞片(鳞片较大，肉眼可见)；各横线不甚清晰，呈斑点状；内区棕色基半部颜色较浅，在中部具一棕色大斑，在前缘中央具一至二个黑色纵纹；中区在翅后缘约5 mm，在中部约10 mm宽；内线接近线形，强烈弯曲，近内线外侧具六至七个黑色不规则形小点，其中位于1A脉上的点为一纵纹，位于中室上方的点为一横纹；中室末端具三个黑色点，呈三角形排列；中室中部具一黑点；外线较清晰，为二列新月形纹(月形纹的凸面向翅基部)，新月纹与翅外缘问约7～8 mm宽；缘毛暗棕色与灰白色相间。

后翅浅灰棕色，翅外缘区浅黑色，中室末端无斑点。前翅反面灰棕色，前缘区和外缘区浅黑色，中室末端具三个黑点，呈三角形排列；翅后缘呈弧形，从横脉纹至翅后缘中央约9mm宽，大于翅后缘长度1/2；缘毛暗棕色和灰白色相间。后翅反面浅灰棕色，前缘区和翅脉棕色；翅外缘具一浅色宽带。雄蛾较小，颜色与雌蛾相似．肛毛簇棕灰色．。雄性外生殖器    背兜两侧稍加宽；钩形突短钩状；基腹弧带状；抱器瓣基半部宽阔，背侧突宽阔，腹侧突呈钩状弯曲，较长；囊形突不发达；阳茎较细长。

本种有6个亚种，它们是：L．serva Fabricius，Type col．Philippien；L．serva albolunulata Moore, Type col. Kaschmir; L.  serva vinacea Moore, Type col. Ca-nara; L.  serva bhascara Moore, Type col. Darjiling; L.  serva sobrina Moore, Type col.Dharmsala; L.  serva iris Strand, Type col. Hongkong.幼虫体长35 mm。

黑褐色，气门线和气门下线的瘤生灰褐色长毛，其余的瘤生褐色短毛。

## 生物学

生活习性  幼虫夜间活动；老熟幼虫在树干缠隙中结茧化蛹；成虫夜间活动，卵产在树干缝隙中；卵块外被雌蛾腹部末端体毛。在云南丽江2600- 3050m成虫于7～8月出现。观察标本  3♂♂3♀，江西苗儿山、1985．Ⅶ．10、王子清采；1♂1♀，湖南张家界金边溪、1988．IX．15、方承莱、赵仲苓采；1♂1♀，四川峨眉山、800～1000m、1974．Ⅵ．1、王子清采；云南丽江、2600m、1989．Ⅵ、王子清采。

寄主植物  榕树。
