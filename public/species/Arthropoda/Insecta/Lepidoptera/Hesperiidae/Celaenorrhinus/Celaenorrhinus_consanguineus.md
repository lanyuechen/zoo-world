# 同宗星弄蝶

**Celaenorrhinus consanguineus**

## 形态描述

雌螨  背板长323-344μm，宽206-230μm，光滑，前侧缘具微弱的线纹。较长的背刚毛相对长度为j1 < j3 < Z4 < s4 < Z5。Z4和Z5具微刺，其余各毛微小且光滑,r3与R1在盾间膜上，且前者长度约为后者的2倍。胸板具胸毛3对，第4对胸毛在小骨板上,生殖板后缘宽68μm，生殖毛1对,腹肛板五边形，前缘宽(82μm:66μm)，肛前毛3对，侧缘稍凹入，星形肛前孔1对，孔距33μm。

腹侧毛4对（ZV1，ZV3，JV4，JV5），JV5长52μm。螯肢定趾多齿，动趾4齿。受精囊杯形，囊颈室节结状。气门沟伸至 j1毛之间。足IV膝节、胫节、基跗节各具巨毛1根，长度分别为：79-86μm，58-65μm，72-75μm。下列各毛长度为：j1 31μm, j3 45-55μm, j4 5μm, j5 5μm, j6 5μm, J2 5, J5 5μm, z2 7μm, z4 7μm, z5 5μm, Z1 7μm, Z4 83-89μm, Z5 148-152μm, s4 93-103μm, S2 7μm, S4 7μm, S5 8μm, r3 21μm, R1 10μm。

雄螨  背板长240μm，宽189μm，光滑。r3与在R1背板上。胸殖板长120μm，宽76μm，胸殖毛5对。腹肛板盾形，长114μm，宽172μm，肛前毛3对，星形肛前孔1对，孔距21μm。导精趾倒L形,主轴长度31μm,足IV膝节、胫节、基跗节各具巨毛1对，分别长度为：48μm，34，52μm。下列各毛长度为：j1 22μm, j3 40μm, j4, j5, j6, J2, J5, z2, z4, z5, S2, S4, S5各为5-7μm, Z4 58μm, Z5 96μm, s4 76μm, r3 19μm, R1 10μm。

## 生物学

本种在海南境内为常见种，栖息于杂草上。

## 生境信息
