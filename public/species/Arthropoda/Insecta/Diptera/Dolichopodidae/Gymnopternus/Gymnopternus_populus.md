# 群行脉长足虻

**Gymnopternus populus**

## 形态描述

体褐至黑褐，毛被短稀(图260)。头光亮，黑褐，细长，为本种显著特征之一；长0.56，宽0.26，眼前部分长:眼前缘以后部分长为4:3；头顶中部光滑无毛，后端呈皱刻状；触角第1节、第2节两端各1/4、第3节端部1/4或1/2和第4节黑褐，第2节中段、第3节基部3/4或1/2黄褐，各节长0.14:0.40:0.24:0.27，各节毛长(第1节除外)稍超过该节直径，第4节毛被密。

前胸背板(图261)长0.42，领宽0.37，后缘宽0.94(短翅型前胸背板(图262)较窄小，长0.36，领宽0.33，后缘宽0.66)；污黑褐，后角略淡，毛被短，极稀；侧缘直，呈狭薄边状；领表面具横皱；胝区稍隆出，浅横皱状，细密，胝后下陷不明显；后叶中部宽阔地凹陷，横皱状。前翅爪片、内革片端部、外革片基部及端部大部以及楔片褐色，内革片基部和中部、以及外革片亚基部浅黄褐色，楔片缝内侧有一淡色小斑；外革片侧缘中部较直(图266)[短翅型亚端部凸出(图265)]；外革片长0.84，楔片长0.44(短翅型中相应为0.62:0.30)；膜片在基部及楔片后角之后有淡色斑，上有3条明显的脉。

喙黑褐，第2—4节长0.22:0.56:0.30。臭腺沟缘直(图263)。足基节和股节黑褐，胫节、跗节黄褐或深褐色，胫节毛长者稍超过该节直径。雄虫阳基侧突宽片状(图264)。体长2.4—2.8。观察标本  2♀，天津八里台，1964.Ⅸ.27；1♀，北京西郊，1973.Ⅶ；1♀，河北蔚县西合营，860m，1964.Ⅵ.10，韩寅恒(IZAS)。

据 Péricart(1972)记载，发现于杨树(Populus spp.)及柳树(Salix spp.)上。

## 国外分布

蒙古，中亚，欧洲。

## 国内分布

天津、北京、河北(蔚县)、甘肃(酒泉)(Elov 和 Kerzhner，1977)
