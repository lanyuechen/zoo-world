# 长鳍美鰕虎

**Callogobius hasseltii**

## 形态描述

测量标本1尾；体长43mm。采自西沙群岛：永兴岛。背鳍VI, I-10;臀鳍I-7；胸鳍16；腹鳍I-5；尾鳍18。纵列鳞34；横列鳞17；背鳍前鳞20。鳃耙1+9。椎骨26枚。体长为体高的5.4倍，为头长的3.4倍。头长为吻长的3.5倍，为眼径的3.6倍，为眼间隔的12.7倍。尾柄长为尾柄高的1.8倍。体延长，前部亚圆筒形，后部侧扁；背缘浅弧形，腹缘平直；尾柄较宽。

头中大，尖突而略平扁，头宽大于头高。头部具6个感觉管孔（B', C D, E, F, G），颊部具4条横列的皮嵴突起（第四条皮嵴突起分为3段）和2条水平状（纵向）皮嵴突起（图418）。吻较长而圆钝。眼中大，背侧位，眼上缘突出于头部背缘。眼间隔狭窄，内凹。鼻孔每侧2个，分离：前、后鼻孔具相互连通的鼻管，前鼻孔位于吻前端背缘，接近于上唇；后鼻孔位于吻部中央的背缘。

口小，前上位，斜裂，下颌突出，长于上颌。上颌骨后端不伸达眼前缘下方。上、下颌齿细尖，3～4行，外行前部齿稍扩大。犁骨、腭骨及舌上无齿。唇厚，较发达。舌细长，游离，前端圆形。鳃孔狭窄，侧位。鳃盖上方仅具1个感觉管孔(H')，前鳃盖骨有3个感觉管孔（M', N, O'）(图418)。峡部宽大，鳃盖膜与峡部相连。鳃盖条5根。

具假鳃。鳃耙短钝。头部除在项部、颊部及鳃盖部被圆鳞外，其余的都裸露无鳞。项部的鳞片向前延伸至眼后缘上方。躯干部及尾部被栉鳞，吻部、颊部及鳃盖部具许多嵴状感觉乳突及感觉管开孔。无侧线。背鳍2个，分离；第一背鳍鳍棘柔软，第三、第四鳍棘最长，平放时，可伸达第二背鳍起点；第二背鳍高于第一背鳍，前部鳍条稍短，后部鳍条较长，平放时，可伸达尾鳍基。

臀鳍与第二背鳍相对，同形，其起点位于第二背鳍第一至第二鳍条的下方，后部鳍条较长，平放时，几乎伸达尾鳍基。胸鳍颇宽，尖圆，稍大于头长，鳍条末端伸越臀鳍起点。腹鳍互相接近，两腹鳍之间的愈合膜不发达，仅存在于基部，故两腹鳍之间的内侧鳍条不愈合，不形成漏斗状的吸盘；内侧鳍条较长，向后不伸达肛门。尾鳍尖矛状，为头长的1.5倍。肛门与第二背鳍起点相对。

雄鱼生殖乳突细长而尖。液浸标本的体上部橙绿色，下部褐色。头部眼后至颊部具1条黑褐色斜纹，项部具3～4条横纹。体侧散具许多不规则的黑褐色云纹，第一背鳍下方的体侧具1条黑褐色横带。第二背鳍下方的体侧具2条黑褐色横带。胸鳍亦具黑褐色云纹状大斑块。腹鳍浅色。尾鳍具多条褐色横带，上半部具1个褐色圆形大斑，约与眼径等大。

## 生物学

长鳍美虾虎鱼为生活在热带沿岸岩礁及珊瑚丛中的暖水性小型底层鱼类。体长50～60mm。

## 国外分布

日本，菲律宾，印度尼西亚，印度及西南太平洋海域。

## 国内分布

分布于西沙群岛、台湾
